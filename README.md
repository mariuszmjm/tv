# TV Polska – aktualizator playlist (pilot)

Projekt katalogowania publicznych odnośników do nagrań z https://tv-polska.eu/ w formacie M3U8, bez kopiowania filmów. Wersja pilotażowa; rzeczywiste źródła MP4/HLS wymagają sprawdzenia. Plan: 12 grup regionalnych, dwie playlisty (wszystkie i turystyka), cykliczna aktualizacja oraz raport CSV. Pliki źródłowe aktualizatora: pakiet TV_Polska_Aktualizator_PILOT.zip.
